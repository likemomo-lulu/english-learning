# 日常英语 App：UI 原型

此预览已接入 v0.7 的 67 章文字初稿和独立的“语句速查”，可用于电脑或手机尺寸试读。0.3.0 Android APK 内置 v0.5 的 54 章，可通过教材内容更新获得全部 67 章；本次不重新打包。安装包和[安装说明](../android-install-guide.md)位于上级目录。

## 查看

- 本机预览地址：http://127.0.0.1:4178/
- 单文件原型：`index.html`。页面代码、样式和图标均已嵌入，不需要额外加载界面依赖。
- 本机预览服务只监听 127.0.0.1，只提供这个原型页面。该地址不是手机安装或长期使用方案。

## 页面

1. 章节：日常 / 旅行 / 职场 / 全部分类、搜索、材料状态、继续学习。
2. 学习：核心句、对话练习、场景变化、语句速查；英文为主，可隐藏中文释义。速查独立展示关键词音标、易错点及本章例句，词语和例句均可点读。
3. 收藏：搜索收藏表达、点读、返回对应章节。
4. 我的：收藏数量、语速、英语音色、字号、中文显隐、教材版本和更新状态、记录导入导出。

原有表达笔记直接展示，未追加速查内容。发音和收藏按钮与角色和表达类型放在同一行，不另占工具行。已学功能及统计已移除；首页不显示英文抬头和大标题；继续学习保留模块名称及英文副标题，去掉示例句和中文翻译；“我的”不再显示主题参考模块。

手机布局更新（2026-10-09）：分类栏独立一行，章节单列展示；长标题与正文自动换行。句子工具、播放控制和主要选项使用至少 44 像素点击区，中文释义与表达笔记使用 14 像素字号。播放器和底部导航分别占用固定位置，正文底部保留滚动空间。电脑宽度仍使用侧栏和双列章节。

- 全套共 804 条核心句、144 段对话、145 个变化分支、222 条核心句笔记、402 个速查条目。

- v0.6 新增 D35「图书馆办卡与借还书」，练习办卡材料、借阅期限、续借、预约、闭馆归还和费用核查；借阅规则为虚构练习设定，不代表各地图书馆通用政策。
- D24–D34 新增电话、租房、报修、支付、外卖、做客、邻里、订阅、与新认识的人互相了解、中国传统节日和中国经典小吃与菜肴；T07–T09 新增航班变更、入境申报与紧急求助；W09–W11 新增客户需求确认、产品演示与面试。新增材料为原创情境练习，不是博主视频字幕。

- 文稿参考博主的场景选题及用户讲义，经改写、扩展，不是已核实的原视频字幕。速查的关键词英美音标逐项核对剑桥词典；词典来源保存在结构化文稿中。已做内容自查和结构校验，尚未做母语者审校。
- 电脑预览点读调用浏览器语音合成；Android APK 使用系统文字转语音引擎，优先选择离线英语音色。断网朗读需要设备已有英语离线语音数据；不是已制作的离线音频包。
- 收藏及设置保存在当前浏览器或手机 App 本地，导入记录采用合并方式。安卓导出使用系统分享面板保存 JSON 备份。
