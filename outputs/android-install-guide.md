# 日常英语 Android 安装说明

版本：0.3.0，个人试用 APK（debug 签名）。构建日期：2026-10-09。

本次更新：内置 v0.5 的全部 54 章文字初稿，并加入教材内容更新。已有收藏和设置可通过覆盖安装保留；直接覆盖安装，不需要卸载旧 App。

2026-10-10：已发布教材 v0.6（内容编号 2026101001），新增 D35「图书馆办卡与借还书」，更新后为 55 章。已安装 0.3.0 的用户只需在“我的 -> 教材内容 -> 检查内容更新”下载；APK 内置底包仍为 v0.5，本次没有重打 APK。

## 安装

1. 将本目录的 `scene-english-0.3.0-debug.apk` 传到安卓手机，例如通过 USB 文件传输。
2. 在手机文件管理器中打开 APK。如果系统询问，允许当前文件管理器“安装未知应用”，然后完成安装。
3. 打开“日常英语”，直接选择章节学习。手机无需安装 Node.js、Android Studio 或 Capacitor。

最低安装版本为 Android 7.0（API 24）。页面使用系统 WebView，建议保持 Android System WebView / Chrome 更新。

## 内容和使用

- 界面和文字已经装入 APK，不需要电脑开机，也不需要固定 IP、局域网或开发服务器。
- 54 章文字初稿：日常 34 章、旅行 9 章、职场 11 章；648 条核心句、118 段对话、119 个场景变化分支、324 个速查条目。
- 学习页展示核心句、对话、场景变化和语句速查。速查独立展示关键词英美音标、易错点和本章例句，支持词语与例句点读。表达笔记直接显示，发音和收藏按钮放在同一行。
- 完整文稿中的词组、替换练习、回应练习和自由任务可在同目录的文稿文件阅读，尚未加入 App 学习页。
- 点击英文或发音图标朗读；底部支持顺序播放、上一句、下一句和语速切换。
- 安卓系统语音不支持逐词暂停，暂停后继续会从当前句开头重播。
- 收藏和阅读设置保存在手机本地，不与电脑浏览器记录自动同步。

## 离线朗读

点读调用手机系统的“文字转语音”引擎，APK 没有内置录制好的音频。

“我的 -> 英语音色”会标注系统报告的“离线”或“联网”音色。默认优先选择美式英语离线音色；手动选择的音色优先。手机必须安装可用英语语音引擎和离线英语语音数据，才能断网朗读。系统标为离线并不保证语音数据已经下载，应以手机实际播放为准。

如果没有声音或提示缺少英语语音，在手机设置中搜索“文字转语音”或“TTS”，选择可用引擎，下载英语语音数据，返回 App 后重新选择音色，并检查媒体音量。不同品牌的设置位置和引擎支持不同。

## 记录备份和更新

- App 启动时自动检查教材更新，也可以在“我的 -> 教材内容 -> 检查内容更新”手动检查。当前教材版本为 v0.5，内容编号 2026100901；App 安装包版本为 0.3.0，两者分别管理。
- 教材从 GitHub 下载并保存在手机本地，成功更新后可断网阅读。下载失败、内容损坏、格式不兼容或保存失败时继续使用原教材，收藏和设置不会被替换。
- GitHub 在部分网络下可能连接失败，App 会自动尝试 jsDelivr 上同一 GitHub 仓库的内容；两个通道均不可用时可稍后重试。备用通道缓存刷新可能较晚。系统点读仍需可用英语音色；教材更新不包含音频文件。
- 0.2.2 及更早的 App 不支持教材更新，需要先覆盖安装本次 0.3.0。后续新增或修订教材可免安装；新功能和原生能力仍需新版 APK。
- 在“我的 -> 导出记录”中生成 JSON 备份，通过系统分享面板选择保存位置。未选择保存目标前，记录仅位于 App 缓存。
- “导入”选择之前的 JSON 文件，将收藏合并，兼容旧版备份。文件上限为 1 MB。
- 电脑预览记录可以先导出，再传到手机后导入。
- 卸载或清除 App 数据会丢失本地记录，操作前先导出到 App 以外的位置。
- 后续版本应保持相同包名和签名，并直接覆盖安装以保留记录。当前包名为 `com.cass.sceneenglish`，使用本机 Android 调试签名；此包用于个人安装，不用于应用商店发布。
